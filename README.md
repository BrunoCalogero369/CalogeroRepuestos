# 🏎️ Calogero Repuestos - E-commerce Catalog

¡Bienvenido al repositorio de la nueva plataforma digital para **Calogero Repuestos**! Este proyecto nació de la necesidad de modernizar la presencia online de un negocio familiar, pasando de una web estática a una aplicación de alto rendimiento.

## 🚀 Demo en Vivo
Puedes ver el proyecto funcionando aquí: [(https://calogerorepuestos.netlify.app/)]

## 🛠️ Tecnologías Utilizadas
* **Framework:** Next.js 14/15 (App Router)
* **Lenguaje:** TypeScript / JavaScript (ES6+)
* **Estilos:** Tailwind CSS (Diseño Mobile-First)
* **Despliegue:** Netlify con CI/CD (Continuous Integration)

## ✨ Características Principales
* **Performance Optimizada:** Utilización de Server Components para una carga ultrarrápida.
* **Catálogo Dinámico:** Sistema de visualización de repuestos y servicios.
* **SEO Local:** Configuración de metadatos para mejorar la visibilidad en búsquedas de Google en la zona de Rosario.
* **Diseño Responsivo:** Adaptabilidad total para que los clientes puedan consultar desde su celular en el taller.

## 📈 Impacto del Proyecto
Este desarrollo permitió digitalizar el catálogo de productos, facilitando la consulta de clientes y reduciendo el tiempo de respuesta en mostrador mediante una interfaz intuitiva y veloz.
